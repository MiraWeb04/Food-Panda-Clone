# Sweet Bites Delivery Website

A simple responsive food delivery website inspired by Food Panda that lets customers browse pastries, iced coffee, hot coffee, frappes, and rice meals. The site includes cart management and a checkout simulation.

## How to use

1. Open `index.html` in your browser.
2. Browse the menu and add items to the cart.
3. Open the cart and checkout with the payment form.

## Files

- `index.html` — main website markup
- `styles.css` — responsive styling
- `script.js` — cart and checkout logic

## Notes

This site is a static demo and uses local storage for cart persistence. The payment checkout is simulated and does not process real payments.
